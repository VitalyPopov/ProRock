# ProRock.Xmlite.Fhir

The units `ProRock.Xmlite.Schema.Fhir` and `ProRock.Xmlite.Schema.Xhtml` in this folder are generated by ProRocket from the
official XML schemas of HL7® FHIR® R4. The sample builds with them as they are: you need the schemas only to generate the
units again - for a newer version, or to see how it is done. The schemas are not included; HL7's notice is in
[THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md).

## The schemas

FHIR R4 (4.0.1): http://hl7.org/fhir/R4/fhir-all-xsd.zip - from it, `fhir-single.xsd` and `fhir-xhtml.xsd`, into this
folder.

## Generating the units

With the CLI of [ProRocket Lite](https://prorock.rocks/prorocket-lite/), in this folder, in PowerShell (give
`ProRocketCli.exe` its full path):

```powershell
ProRocketCli.exe -o . fhir-single.xsd fhir-xhtml.xsd
```
