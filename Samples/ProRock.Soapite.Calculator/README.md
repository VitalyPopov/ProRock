# ProRock.Soapite.Calculator

The units `ProRock.Soapite.Calculator` and `ProRock.Xmlite.Schema.Calculator` in this folder are generated by ProRocket
from the WSDL of a public demo service. The sample builds with them as they are: you need the WSDL only to generate the
units again, or to see how it is done. The WSDL is not included.

## The WSDL

http://www.dneonline.com/calculator.asmx?WSDL - save it into this folder as `calculator.wsdl`.

## Generating the units

With the CLI of [ProRocket Lite](https://prorock.rocks/prorocket-lite/), in this folder, in PowerShell (give
`ProRocketCli.exe` its full path):

```powershell
ProRocketCli.exe -o . calculator.wsdl
```
