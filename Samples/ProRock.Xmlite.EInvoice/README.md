# ProRock.Xmlite.EInvoice

The `ProRock.Xmlite.Schema.*` units in this folder are generated by ProRocket from the official schemas of EN 16931's two
syntaxes. The sample builds with them as they are: you need the schemas only to generate the units again - for a newer
version of a schema, or to see how it is done. The schemas are not included; their notices are in
[THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md).

## The schemas

- **CII**: UN/CEFACT Cross Industry Invoice D16B, from https://github.com/ConnectingEurope/eInvoicing-EN16931, folder
  `cii/schema`: the four `CrossIndustryInvoice_*100pD16B.xsd` files, into `Schemas\cii`
- **UBL**: OASIS UBL 2.4, from https://docs.oasis-open.org/ubl/os-UBL-2.4/: its `xsd\maindoc` and `xsd\common` folders, into
  `Schemas\ubl\maindoc` and `Schemas\ubl\common`

## Generating the units

With the CLI of [ProRocket Lite](https://prorock.rocks/prorocket-lite/), in this folder, in PowerShell (give
`ProRocketCli.exe` its full path). The order of the files matters: the first file to declare a namespace gives its prefix.

```powershell
ProRocketCli.exe -o . Schemas\cii\CrossIndustryInvoice_100pD16B.xsd Schemas\cii\CrossIndustryInvoice_QualifiedDataType_100pD16B.xsd Schemas\cii\CrossIndustryInvoice_ReusableAggregateBusinessInformationEntity_100pD16B.xsd Schemas\cii\CrossIndustryInvoice_UnqualifiedDataType_100pD16B.xsd
```

```powershell
ProRocketCli.exe -o . Schemas\ubl\maindoc\UBL-Invoice-2.4.xsd Schemas\ubl\maindoc\UBL-CreditNote-2.4.xsd (('BDNDR-CCTS_CCT_SchemaModule-1.1', 'BDNDR-UnqualifiedDataTypes-1.1', 'UBL-CommonAggregateComponents-2.4', 'UBL-CommonBasicComponents-2.4', 'UBL-CommonExtensionComponents-2.4', 'UBL-CommonSignatureComponents-2.4', 'UBL-ExtensionContentDataType-2.4', 'UBL-QualifiedDataTypes-2.4', 'UBL-SignatureAggregateComponents-2.4', 'UBL-SignatureBasicComponents-2.4', 'UBL-XAdES01903v132-201601-2.4', 'UBL-XAdES01903v141-201601-2.4', 'UBL-xmldsig-core-schema-2.4', 'UBL-xmldsig1-schema-2.4', 'UBL-xmldsig11-schema-2.4') | ForEach-Object { "Schemas\ubl\common\$_.xsd" })
```
