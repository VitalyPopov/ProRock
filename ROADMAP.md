# Roadmap

Plans, not promises: priorities follow real use. Themes only, no dates. The details of each release are in the
[CHANGELOG](CHANGELOG.md).

## Now

- **Documentation**: a small site with a getting-started guide, Xmlite, Soapite, ProRocket Lite (GUI and CLI), the samples,
  and XML concepts explained for Delphi developers
- **Polymorphic content**: substitution groups and full `xsi:type` - a property typed with a base element or type holds any
  of its derived ones, read and written with the right name
- **ProRocket Lite polish**: the GUI, from real use

## Next

- **Absent vs default**: tell an absent optional value from one equal to its default
- **OOXML**: the spreadsheet schemas generated and tested end to end - the base for Calcite (xlsx and ods, one object model)
- **Android**: a sample app verified on a device

## Later / considering

- **Jsonite**: JSON through the same classes (opens 2.x)
- exact decimals, mixed content with child elements, Graphite (docx and odt)
- considering a commercial edition: native AS4 and XML signatures

## Your schema doesn't generate?

Open an [issue](https://github.com/VitalyPopov/ProRock/issues/new/choose) with the schema (or a link to it) and what went wrong.
Real-world schemas decide what comes next.
