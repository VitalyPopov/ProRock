# ProRock.Soapite.CheckVatService

The units `ProRock.Soapite.CheckVatService` and `ProRock.Xmlite.Schema.CheckVatService` in this folder are generated by
ProRocket from the WSDL of the EU VIES VAT number validation service (European Commission). The sample builds with them as
they are: you need the WSDL only to generate the units again - when the service changes, or to see how it is done. The
WSDL is not included.

## The WSDL

https://ec.europa.eu/taxation_customs/vies/checkVatService.wsdl - save it into this folder as `checkVatService.wsdl`.

## Generating the units

With the CLI of [ProRocket Lite](https://prorock.rocks/prorocket-lite/), in this folder, in PowerShell (give
`ProRocketCli.exe` its full path):

```powershell
ProRocketCli.exe -o . checkVatService.wsdl
```
