# ProRock.Soapite.WsSecurity

The units `ProRock.Xmlite.Schema.WsSecurity` and `ProRock.Xmlite.Schema.WsSecurityUtility` in this folder are generated by
ProRocket from the OASIS Web Services Security 1.0 schemas. The sample builds with them as they are: you need the schemas
only to generate the units again, or to see how it is done. The schemas are not included; the OASIS notice is in
[THIRD-PARTY-NOTICES.md](../../THIRD-PARTY-NOTICES.md).

## The schemas

- https://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-secext-1.0.xsd
- https://docs.oasis-open.org/wss/2004/01/oasis-200401-wss-wssecurity-utility-1.0.xsd

Save both into this folder.

## Generating the units

With the CLI of [ProRocket Lite](https://prorock.rocks/prorocket-lite/), in this folder, in PowerShell (give
`ProRocketCli.exe` its full path):

```powershell
ProRocketCli.exe -o . oasis-200401-wss-wssecurity-secext-1.0.xsd oasis-200401-wss-wssecurity-utility-1.0.xsd
```
